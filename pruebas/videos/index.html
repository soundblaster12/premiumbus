🎬 Grabación de Videos de Pruebas

Instrucciones para grabar cada prueba en formato MP4

✅ Los 10 demos de pruebas están listos. Cada archivo HTML se auto-ejecuta con animaciones profesionales. Solo necesitas grabar la pantalla mientras se reproducen.

📋 Paso 1: Preparar el grabador de Windows

Presiona Win + Alt + R para iniciar/detener la grabación con Xbox Game Bar.

Primera vez: Si no funciona, ve a Configuración → Juegos → Xbox Game Bar y actívalo.

Alternativa: Usa la Herramienta de Recortes (Snipping Tool) → clic en 📹 para grabar pantalla.

🎥 Paso 2: Grabar cada prueba

Para cada archivo HTML:

  1. Abre el archivo HTML en Chrome (doble clic)
  2. Presiona F11 para pantalla completa
  3. Presiona Win+Alt+R para grabar
  4. Espera a que aparezca "✅ PRUEBA APROBADA" (~15-20 seg)
  5. Presiona Win+Alt+R para detener
  6. Presiona F11 para salir de pantalla completa

📂 Paso 3: Encontrar los videos

Los videos MP4 se guardan automáticamente en:
C:\Users\GAMER\Videos\Captures\

Renombra cada archivo al nombre de la prueba correspondiente.

⚠️ Importante: Cada demo se auto-ejecuta UNA vez al abrir. Si necesitas repetirlo, recarga la página con F5.
