📋 Instrucciones:
1. Las guías de configuración (04_Guias_Configuracion/) ya están creadas ✅
2. El LEEME_PRIMERO.txt ya está creado ✅
3. Debes copiar manualmente el .exe, el código fuente y los .docx a sus carpetas
4. Abajo tienes los comandos de PowerShell para copiar todo automáticamente

🖥️ Comandos para copiar todo automáticamente:

# Ejecutar en PowerShell desde la carpeta del proyecto: $base = "C:\Users\GAMER\OneDrive\Documentos\PremiumBus" $usb = "$base\Entrega Sistema USB" # 01 - Instalador New-Item "$usb\01_Instalador" -ItemType Directory -Force Copy-Item "$base\dist\Instalador_PremiumBus_v5.exe" "$usb\01_Instalador\" -Force # 02 - Código Fuente New-Item "$usb\02_Codigo_Fuente" -ItemType Directory -Force Copy-Item "$base\src" "$usb\02_Codigo_Fuente\src" -Recurse -Force Copy-Item "$base\api" "$usb\02_Codigo_Fuente\api" -Recurse -Force Copy-Item "$base\index.html" "$usb\02_Codigo_Fuente\" -Force Copy-Item "$base\sw.js" "$usb\02_Codigo_Fuente\" -Force Copy-Item "$base\manifest.json" "$usb\02_Codigo_Fuente\" -Force Copy-Item "$base\setup_db.php" "$usb\02_Codigo_Fuente\" -Force # 03 - Documentación New-Item "$usb\03_Documentacion" -ItemType Directory -Force Copy-Item "$base\Manual_Usuario_PremiumBus_v5.docx" "$usb\03_Documentacion\" -Force Copy-Item "$base\Documentacion_Sistema_PremiumBus_v_*.docx" "$usb\03_Documentacion\" -Force Copy-Item "$base\SRS_PremiumBus.docx" "$usb\03_Documentacion\" -Force Copy-Item "$base\Programa de Capacitacion PremiumBus*" "$usb\03_Documentacion\" -Force # 05 - Presentación (si ya la generaste) New-Item "$usb\05_Presentacion" -ItemType Directory -Force # Copia la presentación desde tu carpeta de descargas: # Copy-Item "$env:USERPROFILE\Downloads\Entrega_Sistema_PremiumBus.pptx" "$usb\05_Presentacion\" -Force Write-Host "✅ ¡Carpeta USB lista!" -ForegroundColor Green
