⭐ Administrador Principal (ID: 1)

El Admin Principal tiene permisos exclusivos que los otros 9 admins NO tienen:
  • 🗑️ Eliminar usuarios del sistema (borrar cuentas completas)
  • 🔒 Solo el usuario con ID = 1 puede ejecutar la función deleteUserById()
  • Al eliminar un usuario, se borran también sus compras, historial y foto de perfil

Permisos de los 9 Admins Secundarios

Los admins con ID 2-10 pueden:
  • 📊 Ver estadísticas del dashboard (usuarios, ventas, ingresos, ocupación)
  • 🚌 Gestionar y visualizar rutas
  • 👥 Ver el listado de usuarios registrados
  • 🎫 Ver historial completo de compras
  • 📥 Exportar reportes a Excel
NO pueden: Eliminar usuarios ni eliminar otras cuentas admin.

¿Dónde se definen las cuentas?

Modo localStorage (demo): Las cuentas se definen en:

📂 src/services/AuthService.js → método _initializeDefaultUsers() (líneas 44-56)

Modo MySQL (producción): Las cuentas se insertan desde:

📂 api/setup.sql → INSERT INTO usuarios ... 📂 setup_db.php → Se ejecuta al configurar la BD desde el navegador

Cambiar Contraseña de un Admin

Cada admin puede cambiar su contraseña desde: Perfil → Configuración de Cuenta → Cambiar Contraseña

🔴 Recomendación de Seguridad: Cambie la contraseña por defecto (admin123) de TODAS las cuentas admin inmediatamente después de la instalación.
