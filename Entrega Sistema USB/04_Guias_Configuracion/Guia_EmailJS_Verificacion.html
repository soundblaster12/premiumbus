📧 Guía de Configuración — EmailJS

Verificación de correo para nuevas cuentas y recuperación de contraseñas en PremiumBus

¿Qué es EmailJS?

EmailJS es un servicio que permite enviar correos electrónicos directamente desde el navegador (frontend) sin necesidad de un servidor de correo propio. PremiumBus lo utiliza para:

  • Verificación de nuevas cuentas: Envía un código de 6 dígitos al correo del usuario al registrarse.
  • Recuperación de contraseña: Envía un código de verificación para restablecer la contraseña olvidada.
⚠️ Modo Demo: Si EmailJS no está configurado, el sistema funciona en "modo demo": muestra el código de verificación directamente en pantalla (sin enviar email real). Esto es útil para pruebas.

Configuración Paso a Paso

1Crear cuenta en EmailJS

Ir a https://www.emailjs.com/ → Click en "Sign Up Free"
La cuenta gratuita permite 200 emails al mes, suficiente para uso normal.

2Conectar un servicio de correo (Gmail)

En el dashboard de EmailJS:
Email Services → Add New Service → Gmail
Autoriza tu cuenta de Gmail. Se generará un Service ID (ej: service_2gestc9).

3Crear un template de email

En Email Templates → Create New Template, configura el email con estas variables:

Asunto: 🔐 PremiumBus — Código de Verificación: {{code}} Cuerpo: Hola {{to_name}}, Tu código de verificación para PremiumBus es: 🔑 {{code}} Este código expira en 10 minutos. Si no solicitaste este código, ignora este mensaje. — Equipo PremiumBus

Se generará un Template ID (ej: template_jjy8tk8).

4Obtener la Public Key

En Account → API Keys, copia tu Public Key (ej: cMCbDTcQu6cFcHbvh).

5Configurar en el código de PremiumBus

Abrir el archivo: src/services/EmailService.js

Buscar las líneas 15-19 y reemplazar con tus datos:

const EMAILJS_CONFIG = { publicKey: 'TU_PUBLIC_KEY', // ← Pegar tu Public Key aquí serviceId: 'TU_SERVICE_ID', // ← Pegar tu Service ID aquí templateId: 'TU_TEMPLATE_ID', // ← Pegar tu Template ID aquí };
✅ ¡Listo! Ahora al registrarse o recuperar contraseña, el sistema enviará el código de verificación al correo real del usuario.

Variables del Template

El sistema envía estas variables al template de EmailJS:

  • {{to_email}} — Correo del usuario destino
  • {{to_name}} — Nombre del usuario
  • {{code}} — Código de 6 dígitos generado
  • {{app_name}} — Siempre "PremiumBus"

Archivo que se modifica

📂 PremiumBus/ └── src/ └── services/ └── EmailService.js ← SOLO este archivo se modifica

Flujo de Verificación

1. Usuario se registra o solicita recuperar contraseña
2. El sistema genera un código aleatorio de 6 dígitos
3. Se almacena temporalmente (expira en 10 minutos)
4. Se envía por email via EmailJS (o se muestra en pantalla en modo demo)
5. El usuario ingresa el código en los 6 campos de verificación
6. El sistema valida el código y procede
