🗺️ Guía — GPS y Mapas Interactivos

Funcionamiento del sistema de mapas, geolocalización y simulación de buses en PremiumBus

Tecnología Utilizada

Leaflet.js + OpenStreetMap (OSM)
PremiumBus utiliza Leaflet.js, una librería open-source de mapas interactivos, conectada a los tiles gratuitos de OpenStreetMap. No requiere API key ni pagos, a diferencia de Google Maps.

Funcionalidades del Mapa

1. 🗺️ Visualización de Rutas

Cada una de las 30 rutas urbanas de SLP se dibuja como una polyline (línea azul neón) sobre el mapa, conectando todas las paradas definidas.

// MapService.js — renderTrip() L.polyline(routeCoords, { color: '#00D4FF', // Azul neón weight: 5, // Grosor de línea opacity: 0.9, // Transparencia }).addTo(map);

2. 📍 Marcadores de Paradas

Cada parada se muestra con un marcador visual diferenciado:

3. 🚌 Simulación de Bus en Tiempo Real (Modo "En Vivo")

El sistema simula el movimiento de un autobús a lo largo de la ruta seleccionada:

  • Interpolación densa: Se generan 80 puntos intermedios entre cada par de paradas para movimiento fluido
  • Trail visual: Una línea azul marca el recorrido ya completado
  • Seguimiento automático: El mapa sigue al bus automáticamente (estilo Uber)
  • Panel ETA: Muestra la próxima parada y el progreso estimado
  • Loop continuo: La simulación se repite automáticamente al finalizar
// Algoritmo de simulación (MapService.js — startBusSimulation) 1. Obtener paradas de la ruta seleccionada 2. Generar ruta densa interpolada (80 puntos por segmento) 3. Crear marcador de bus con animación de pulso 4. Cada 60ms: mover bus al siguiente punto 5. Actualizar trail (recorrido completado) 6. Mover mapa para seguir al bus (panTo animado) 7. Detectar en qué parada se encuentra 8. Al llegar al final → reiniciar loop

4. 📍 Geolocalización del Usuario (GPS Real)

El botón "Mi Ubicación" utiliza el GPS real del dispositivo:

// MapService.js — showUserPosition() navigator.geolocation.getCurrentPosition( successCallback, // Muestra marcador azul pulsante errorCallback, // Maneja errores de permisos { enableHighAccuracy: true, // GPS de alta precisión timeout: 15000, // Espera máximo 15 segundos maximumAge: 30000, // Cache de 30 segundos } );
⚠️ Requisitos para GPS:
  • El dispositivo debe tener GPS habilitado
  • El usuario debe permitir el acceso a la ubicación
  • En PC/escritorio: usa la ubicación aproximada por WiFi
  • En Android/iOS: usa el GPS de alta precisión del dispositivo

5. 🔄 Tracking Continuo

El sistema también soporta watchPosition() para seguimiento continuo de la ubicación del usuario mientras se mueve.
